# 3D Models

This repository contains 3D-printable models, OpenSCAD sources, and generated print files that I've created.

## Models

| Model | Description | Source |
|---|---|---|
| [ROG Bulwark Dock Shim](ally_bulwark_shim/) | Shim that lets the 2023 ROG Ally stand upright in the ROG Bulwark Dock. | [OpenSCAD](ally_bulwark_shim/ally_bulwark_shim.scad) |

## Repository layout

Each model is kept in its own directory and generally includes:

- An OpenSCAD source file for customization and regeneration.
- A `README.md` with fit, printing, and assembly details.
- Generated formats such as STL or 3MF when available.

## Using a model

Open each model's directory for project-specific measurements and instructions.

Open `.scad` files with [OpenSCAD](https://openscad.org/) to adjust parameters. STL and 3MF files can be imported directly into most slicers.
